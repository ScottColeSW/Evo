# What is unlocked, and how

Generated by `scripts/action_unlocks.py` from the code on every run (do not edit by hand). Each action appears under the era that lists it. "Free with the era" means nothing beyond the era gates it (the action is always on the menu once the era arrives and the tribe has the plain wood, stone or food it costs). Everything else is a gate. Era gates themselves are in `backend/eras.py` (`requires_population`, `requires_ready`, the 50-cycle floor).

## Menu sets and locks

Some rules replace the menu with a fixed set of actions. They are mechanics, not nudges (`docs/NUDGE-AUDIT.md`).

- **pre-settlement menu**: BREED, GATHER_FOOD, GATHER_WATER, RAID, RELOCATE, SCOUT
- **survival crisis menu**: CATCH_FISH, COOK_FOOD, GATHER_EGGS, GATHER_FOOD, GATHER_WATER, HUNTING_PARTY, HUNT_DEER, PLANT_CROP, SCOUT
- **needs a living rival**: DECLARE_ALLIANCE, DECLARE_CONQUEST, DECLARE_WAR, RAID, SEND_TRADE_EMISSARY, SPY, TRADE
- **final-era lock (rival alive)**: BUILD_BARRACKS, BUILD_KEEP, BUILD_KITCHEN, BUILD_LONG_HOUSE, BUILD_VESSEL, CATCH_FISH, COOK_FOOD, DECLARE_ALLIANCE, DECLARE_CONQUEST, DEPART, GATHER_EGGS, GATHER_FOOD, GATHER_STONE, GATHER_WATER, GATHER_WOOD, HUNTING_PARTY, HUNT_DEER, PLANT_CROP, SCOUT, TRAIN_BATTALION, UPGRADE_BARRACKS
- **once the vessel stands**: BUILD_JOINT_CASTLE, CATCH_FISH, COOK_FOOD, DECLARE_ALLIANCE, DECLARE_CONQUEST, DEPART, GATHER_EGGS, GATHER_FOOD, GATHER_WATER, HUNTING_PARTY, HUNT_DEER, PLANT_CROP, SCOUT

Also removed from the menu without a table entry: an action already tried too often (the repetition guard), an action on cooldown (DMM, conquest, warehouse upgrade), the material gathers once a build can be paid, and anything a survival crisis or an unfinished wall section narrows (see `Simulation._prepare_turn`).

BUILD_JOINT_CASTLE

These are in the registry but come from somewhere else (for example BUILD_JOINT_CASTLE is added to the menu for two allied top-era tribes).
